# Checklist de preparación del proyecto

- [ ] Propósito, usuarios y KPI documentados.
- [ ] Alcance/no objetivos aceptados.
- [ ] Riesgos de seguridad, datos y dominio evaluados.
- [ ] Stack y versiones elegidos conscientemente.
- [ ] Entornos, secretos y persistencia definidos.
- [ ] Arquitectura y propietarios de estado/identidad documentados.
- [ ] Roles y agente de Quality **realmente invocable** verificados.
- [ ] Repo privado y protección de rama configurados.
- [ ] Pipeline de CI ejecutado y evidencia conservada.
- [ ] Matriz de tests del producto preparada.
- [ ] Primera misión creada.
- [ ] Gate 1 sometido a revisor independiente.
- [ ] Despliegue requiere autorización independiente.

No marcar checks por mera intención: adjuntar evidencia y responsable.
