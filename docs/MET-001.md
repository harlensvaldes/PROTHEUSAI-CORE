# MET-001 — Medición local de respuestas Codex

Adaptación del extractor de RETRO-004: lee JSONL locales, selecciona `token_usage_record.payload.session_id`, corta por fecha exclusiva, deduplica por `response_id` y suma únicamente `payload.usage`. No suma contadores acumulativos `token_count`; podrían contener consumo heredado. La entrada incluye caché y la salida incluye razonamiento. No se exportan mensajes ni prompts.

```powershell
python scripts/met001.py --sessions "$env:USERPROFILE/.codex/sessions" --session-id ID_RAIZ --cutoff 2026-11-06T13:34:54.524Z --output ./metricas
python -m unittest discover -s tests -p test_met001.py
```

El programa produce `metricas.json` y `metricas.md` de un único resultado. No requiere servicio ni participación de agentes individuales. El JSON conserva archivo, línea, fecha y campo para cada respuesta. Datos ausentes o sospechosos se señalan; la ausencia de anomalías no demuestra que los registros estén completos. Los modelos son los declarados en `turn_context`, no facturación. Los parentescos se toman de `session_meta.source.subagent.thread_spawn` cuando el hilo coincide; no demuestran aislamiento. Los ciclos de revisión son desconocidos si el runner no los identifica de manera estructurada.

Opcional `--phases archivo.json`: lista de objetos `{"name":"fase", "start":"2026-01-01T00:00:00Z"}`. Duración es tiempo transcurrido entre límites configurados o el corte, no tiempo activo; atribución por ventana, no prueba de actividad. Si no se configura, la fase es desconocida.

Opcional `--prices archivo.json`: objeto con `currency`, `effective_date`, `source` y `models`, cuyas claves de modelo contienen precios por millón `input`, `cached_input`, `cache_write_input` y `output`. Acepta solo tarifas planas: no aplica umbrales, descuentos ni recargos. Su resultado es hipotético, puede ser parcial y no representa un cargo real. Sin evidencia de factura, el coste real es desconocido; una suscripción mensual es gasto fijo informado, no coste atribuido automáticamente a una misión. No pasar precios escalonados como si fueran planos.

Comparación local: con la raíz de RETRO-004, carpeta de sesiones del 6 de noviembre de 2026 y corte `2026-11-06T13:34:54.524Z`, se observaron 936 respuestas, 175.627.309 tokens de entrada, 174.119.936 de caché incluida, 257.151 de salida y 175.884.460 en total: coincide con la extracción histórica. La comparación no valida facturación, cobertura completa ni compatibilidad con otros runners. Para costes escalonados, conservar el análisis específico histórico hasta disponer de soporte explícito y probado.
