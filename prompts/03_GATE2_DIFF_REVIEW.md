# Prompt · Revisión independiente Gate 2

Actúa como revisor distinto del implementador. Confirma independencia real y acceso a diff, plan y pruebas. Compara el cambio exacto con Gate 1 aprobado, verifica consumidores, regresiones, alcance, seguridad, accesibilidad, persistencia y tests eliminados. Identifica cambios previos ajenos a esta misión. Emite hallazgos con severidad, archivo/línea y corrección mínima. Si cambió diseño crítico, exige reabrir Gate 1. No asumas que compilar significa corrección. No modifiques código.
