# Prompt · Inicio de un proyecto nuevo

Actúa como arquitecto del proyecto. Antes de desarrollar, lee `AGENTS.md`, `START_HERE.md`, `docs/QUALITY_POLICY.md` y las plantillas. Ayúdame a completar el Project Charter y la arquitectura según mi idea. **No presupongas stack, presupuesto, usuarios ni restricciones**. Identifica decisiones que requieren mi aprobación y evalúa riesgos. Después crea la primera misión con criterios verificables y prepara Gate 1. No escribas código productivo ni apruebes tu propio plan.
